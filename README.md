# ForgeRaft

ForgeRaft is a distributed, event-driven platform leveraging real-time-processing and auto-scaling to optimize complex data workflows and scheduling.

ForgeRaft is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/ForgeRaft.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

To configure ForgeRaft, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
